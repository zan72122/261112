# ぷかぷか！あひるちゃんのおふろ (261112-2 / gf-261112-nx2)

`format_id: scene3d_life` / `style_id: fable_photoreal` / `subject: free`

親一羽・子一羽のあひるを、家庭の浴室で「ためる → 泡を混ぜる → 浮かべて洗う → 排水して拭く → 寝かせる」まで世話する、文字なし・指一本の 3D あそび。

- 遊ぶもの: `index.html` 1 ファイル(three.js・画像・音・フォールバック静止画をすべて埋め込み。外部読み込みなし。`file://` でも Pages のサブフォルダでもそのまま動く)
- サムネイル: `thumb.png`(実画面から撮影)
- 検証記録: `VERIFY.md`(測定環境・実測値・未検証事項)

## 操作 (6 種類、すべて一本指)

| 対象 | 操作 | 起きること |
|---|---|---|
| 蛇口の取っ手 | 横(円弧)にドラッグ / タップ | 開度と給水量が連続で変わる。タップは小さく開閉 |
| 水面 | なぞる | なぞった向きへ水が押され、波が壁で返り、泡が流れに乗る |
| あひる | 胴をドラッグ | 腹を支えて運ぶ。浴槽では水深に応じて立つ／浮く。タオル・寝床へ広く吸着 |
| シャワー | 持ち手をドラッグ | 動かした向きへ水流。離すと止まり受けへ戻る |
| 栓の輪 | 上へ引く / 下へ戻す | 引いた分だけ排水。途中位置も有効 |
| タオルの端 | つかんで羽をなぞる | 押さえた端の近くがよく拭け、その布に濡れ色が広がる |

## 中の仕組み (`src/`)

| ファイル | 役割 |
|---|---|
| `layout.js` | 浴室の寸法と浴槽内面の高さ関数(全系で共有) |
| `water.js` | heightfield の波(壁と親で反射)、粗い流速場(非圧縮化で回り込み)、水位⇔体積表、押しのけ、オーバーフロー、縁に乗る水、寿命つき泡粒子、しぶき |
| `duck.js` / `duckmesh.js` | 距離関数 + Surface Nets で起こした親子の形、羽の地図、産毛の層、部位別(頭・背・左・右)の濡れと泡、浮力・歩行・寝姿 |
| `cloth.js` | 質点 15×23 の Verlet 布(タオル)。あひるの球と衝突、濡れの受け渡し・拡散 |
| `tools.js` | 蛇口・シャワー(水流の当たりと泡の受け渡し)・栓と鎖 |
| `game.js` | Pointer Events、つかむ対象の選択、段階の解放、場面(画角)の切替、お手本の指、寝かしつけとはなまる |
| `env.js` / `textures.js` | 浴槽・タイル・デッキ・窓・寝床と、コード生成の質感テクスチャ |
| `audio.js` | Web Audio による合成音(水・シャワー・排水・鳴き声・寝息・はなまる) |
| `save.js` | 版・型・範囲を検証する保存/復元 |
| `main.js` | 起動、WebGL 可否の判定、固定ステップの物理、動的解像度と低負荷モード、非表示時停止 |

共有状態 → 相互作用の例: 水位と水中体積 → 浮力と押しのけ → 縁へ乗る水 / 親の位置 → 波と流れの遮り → 泡の分かれ方と子の揺れ / 羽の泡 × シャワーの向き → 泡の行き先 / 羽の濡れ × 触れた布 → 布の濡れ色と寝床の水跡。

## ビルド (開発時のみ)

```sh
cd tools && npm install && node build.mjs   # src/ と three.js を index.html へ埋め込む
```

完成品の `index.html` はビルド不要。`tools/fallback.jpg`(WebGL が使えない端末向けの静止画)もこのとき埋め込まれる。

## 検証の再実行

```sh
cd tools
export NODE_PATH=<playwright のある node_modules>
node play.cjs 820 1180   # 通し遊び(375 667 / 390 844 / 820 1180 / 1180 820)
node disc.cjs d2         # 発見の比較実験 d2 d3 d4 d5 d7
node robust.cjs          # 複数指・連打・回転・非表示復帰・保存拒否/破損・WebGL失敗・音拒否・放置・自動低負荷・サブフォルダ配信
node perf.cjs            # 場面ごとの fps (ヘッドレス)
node report.cjs          # results/*.json → VERIFY.md
```

検証用の URL 引数(遊びの内容は変えない): `fresh=1` 保存を読まない / `q=high|low` 品質固定 / `rs=0.3` 解像度倍率 / `lite=1` 産毛の層を省略 / `simcap` 1 フレームに進める物理時間の上限 / `scene=1..5` 初期画角。
