# せんたくびより！くるくるドラムとおひさま（261112-1）

`format_id: scene3d_life` / `style_id: fable_photoreal` / `subject: no_animal_princess`

5歳向け・文字なし・指1本の洗濯あそび。苺柄シャツ・縞タオル・靴下一組の同じ4枚が、
「入れる → 洗う → 脱水 → 干す → 畳んで渡す」の五場面を状態（柄・表裏・面ごとの水分・包んだ靴下・
留め位置・折り目・収納位置）を保ったまま通ります。

- 遊ぶ: `index.html` を開くだけ（`file://` でも Pages のサブフォルダでも同じ。外部読み込みなし・実行時ビルド不要）
- サムネイル: `thumb.png`（実画面のスクリーンショットから作成）

## フォルダ構成

| パス | 内容 |
|---|---|
| `index.html` | 完成品。CSS・JS（three.js r160 を含む）・代替静止画をすべて埋め込んだ1ファイル |
| `thumb.png` | 実画面から作ったサムネイル |
| `src/` | 開発用ソース（ES modules）。`index.html` はここから生成 |
| `tools/build.mjs` | `src/` と three.js を1ファイルに束ねる開発時ビルド。`tools/fallback.jpg`（実画面）を代替静止画として埋め込む |
| `verify/` | ヘッドレス検証スクリプト・結果JSON・スクリーンショット・検証記録 `VERIFY.md` |

### `src/` の役割

| ファイル | 役割 |
|---|---|
| `main.js` | 起動、レンダラ、カメラ（場面ごとの構図・移動）、Pointer Events、かご、物理ループ、品質調整 |
| `cloth.js` | 布：少数質点のPBD＋Catmull-Rom細分化の二重シェル描画、面ごとの水分・汚れ、平置き／折りレイアウト |
| `sim.js` | 床・かご・洗濯機（投入口の縁）との当たり、布同士の反発、かごへ落ち着く力 |
| `washer.js` | つまみ1つの運転（給水→すすぎ→排水→脱水）、回転座標での布物理、水面heightfield、泡、窓の滴、水分の出入り |
| `dry.js` | 物干し台と2本の棒、掛ける／滑らす／引いて送る、ばさみ、風と風よけ、面ごとの乾き、通り雨と軒 |
| `fold.js` | 平置き、指に追従する折り（端を引くと開く）、引き出し収納、家族の人物、手渡しとはなまるカード |
| `hint.js` | 約4秒無操作のとき、その工程で一度だけ出る指のお手本 |
| `save.js` | 版・値域を検査する保存／復元（拒否・破損時はメモリ上で継続／初期状態から） |
| `audio.js` | Web Audio による合成音（素材ファイルなし） |
| `fx.js` | 寿命つき粒子（滴・雨） |
| `tex.js` | 手続き生成テクスチャ（苺柄・縞・木・タイル・金属・はなまる等。外部素材なし） |
| `world.js` | 実寸の洗濯室・洗濯機・ベランダ・物干し台・カウンターの形状 |

## ビルド（開発時のみ）

```sh
npm i            # three@0.160.0 と esbuild（devDependencies）
node tools/build.mjs
```

## 検証

`verify/VERIFY.md` に、実施範囲・実測値・未確認事項をまとめています。

```sh
node verify/play.js      # 実タッチ入力（CDP → Pointer Events）で投入からはなまるまで通し、七つの発見を確認
node verify/robust.js    # 追加指・中断・連打・回転・非表示・保存拒否/破損・WebGL失敗・音拒否・低負荷・両起動方式
node verify/shots.js     # 4サイズ×5場面のスクリーンショットとfps
```

URLの補助パラメータ（遊びには不要）: `?low=1` 低負荷モードを強制、`?fresh=1` 保存を読まずに開始、
`?steps=N&dtmax=S` 低fps環境でも実時間に近い速さで物理を進める（ヘッドレス検証用）。
